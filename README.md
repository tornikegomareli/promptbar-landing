# promptbar-landing

Landing page for [PromptBar](https://github.com/tornikegomareli/PromptBar) — a native
macOS menu bar prompt compiler powered by Apple's on-device Foundation Models.

Live: https://tornikegomareli.github.io/promptbar-landing/

A single static `index.html` with no build step. Screenshots in `assets/` are captured
from the shipping app.
